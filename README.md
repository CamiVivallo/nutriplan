# NutriPlan

Aplicación web educativa para descubrir recetas según la despensa, el presupuesto en pesos chilenos y las preferencias alimentarias.

## Iniciar

```bash
npm install
npm run dev
```

## Funciones V1

- Búsqueda y filtros de recetas: proteína, calorías, vegano, vegetariano y sin gluten.
- Despensa personalizable y cálculo de ingredientes disponibles o faltantes.
- Presupuesto y estimación de costo adicional.
- Cálculos orientativos de macros por porción.
- Persistencia local de preferencias.

## Stack

React + TypeScript + Vite.

**Importante:** datos nutricionales y precios de demostración; no sustituyen consejo médico o de nutrición. No se utiliza información clínica para recomendar dietas terapéuticas.

## Hoja de ruta

Base de datos, cuentas de usuario, planificación semanal, ingredientes provenientes de fuentes confiables y pruebas automatizadas.
